# Information Security Management System (ISMS) Implementation

**ISO/IEC 27001:2022 & NIST CSF 2.0 — Case Study: Digital Horizons Bank**

---

## 📋 Overview

This repository contains a complete Information Security Management System (ISMS) documentation package, designed and implemented according to **ISO/IEC 27001:2022** and aligned with the **NIST Cybersecurity Framework (CSF) 2.0**, based on a realistic case study of a fictional Saudi bank, **Digital Horizons Bank**.

The project was developed as a graduation/course project for the Information Security Management Systems course, covering the full lifecycle of ISMS design: from initial gap analysis to certification readiness assessment. It integrates international standards (ISO/IEC 27001, ISO/IEC 27002, ISO/IEC 27005) with the NIST CSF 2.0 core functions (Govern, Identify, Protect, Detect, Respond, Recover) to ensure a robust, defense-in-depth security posture.

---

## 🎯 Project Objectives

- Conduct a comprehensive gap analysis against **ISO/IEC 27001:2022** requirements (clauses 4–10 and all 93 Annex A controls) and map them to **NIST CSF 2.0** subcategories.
- Build an asset-based information asset inventory and risk register using **ISO/IEC 27005** risk management guidelines.
- Design the foundational ISMS documents: context & scope, information security policy, objectives, risk methodology, risk appetite, and Statement of Applicability (SoA).
- Develop supporting policies and procedures: Acceptable Use Policy, Incident Response, Business Continuity & Disaster Recovery, Secure Operating Procedures, and Secure Configuration Baseline.
- Establish monitoring, internal audit, and continual improvement mechanisms aligned with **NIST CSF 2.0** and **ISO/IEC 27001:2022**.
- Assess the organization's readiness for external **ISO/IEC 27001:2022** certification audit.

## 🧩 Methodology

The project follows the **Plan–Do–Check–Act (PDCA)** cycle mandated by **ISO/IEC 27001:2022**, integrated with the **NIST CSF 2.0** core functions:

| Phase | ISO/IEC 27001:2022 | NIST CSF 2.0 |
|-------|-------------------|--------------|
| **Plan** | Context analysis, gap assessment, asset inventory, risk assessment | **Govern**, **Identify** |
| **Do** | Policy and procedure development, control implementation per the SoA | **Protect** |
| **Check** | Monitoring & measurement, internal audit | **Detect** |
| **Act** | Corrective actions, document updates, certification readiness | **Respond**, **Recover** |
